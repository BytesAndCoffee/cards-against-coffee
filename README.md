# Archived: Cards Against Coffee

This repository has moved to [Bad Decisions](https://github.com/BytesAndCoffee/bad-decisions),
the reusable engine and service for fill-in-the-blank party card games.

Use the new packages:

- [`bad-decisions`](https://pypi.org/project/bad-decisions/) — server and engine
- [`bad-decisions-client`](https://pypi.org/project/bad-decisions-client/) — cross-platform `regret` client

The historical source remains available here for provenance. It is archived and
will not receive updates.
